# Диспетчер инцидентов

Система управления инцидентами и голосового оповещения персонала с интеграцией Matrix и Asterisk.

## Возможности

- 🚨 **Голосовой обзвон** — автоматический звонок на мобильные, внутренние номера и громкоговорители
- 💬 **Matrix-уведомления** — текстовые оповещения в комнаты локаций
- 🎙️ **Студия записи** — запись и конвертация аудио прямо в браузере
- 📊 **Единая история** — все события и кампании в одном месте
- 🏭 **Цеховые пульты** — упрощённый интерфейс для рабочих мест

## Архитектура

Система состоит из трёх основных компонентов:

- **incident-dispatcher** — FastAPI-приложение, оркестратор оповещений
- **voice-api** — сервис голосового обзвона (Asterisk AMI)
- **Matrix-бот** — отправка уведомлений в комнаты
