# Руководство пользователя

Диспетчерский пульт системы оповещения: запуск обзвонов, управление событиями, студия записи собственных сообщений и контроль здоровья системы.

Адрес пульта: `https://it-srv.vpk-oil.ru/incident-dashboard/`
Доступ: только с разрешённых IP-адресов (белый список локации/дашборда).

---

## Системный светофор

Круглый индикатор в левом верхнем углу — здоровье всей системы **до** запуска оповещения.

| Цвет | Значение |
|---|---|
| 🟢 Зелёный | Все компоненты в норме |
| 🟡 Жёлтый | Есть предупреждения (тревога/внимание на локациях) |
| 🔴 Красный | Критично: обзвон или уведомления могут не пройти |

Нажмите на индикатор — откроется панель «Состояние системы»:

- **Проблемы** — человекочитаемый список того, что не так;
- **Телефония** — статус AMI-соединения и каждого транка:
  - 🟢 транк свободен, 🟡 есть активные звонки, 🔴 транк забит, ⛔ нет регистрации у провайдера (внешние звонки не пройдут!);
- **Matrix** — жив ли бот и его токен: если токен протух, текстовые и голосовые уведомления в комнаты не уходят, и вы увидите это здесь, а не постфактум.

> Правило: не запускайте боевое оповещение при красном светофоре без понимания причины.

## Вкладка «Локации»

Карточки локаций (склад, цеха, БПЛА и т.д.) с текущим режимом: **НОРМА / ВНИМАНИЕ / ТРЕВОГА** (цвет рамки карточки).

### Сценарии оповещения

В карточке перечислены сценарии (шаблоны) локации. Первый виден сразу, остальные — по кнопке «⋯ Все сценарии (N)». Бейдж `IVR: код` означает, что сценарий можно запустить звонком на внутренний номер и вводом кода.

Кнопка **«▶ Запустить обзвон»** — немедленный голосовой обзвон списка локации по выбранному сценарию + событие в Matrix-комнату.

### Список оповещения

Кнопка **«👥 Список оповещения (N)»** открывает модальный окно с мастер-списком абонентов локации (номер, код, описание) и поиском по любому полю. Список показывает, **кто реально получит звонок**.

### Активные события

Блок «🔔 Активные события» — незакрытые ВНИМАНИЯ и ТРЕВОГИ с комментарием, временем и источником. Крестик закрывает событие вручную.

### Кнопки управления карточкой

| Кнопка | Действие |
|---|---|
| ⚠️ Вним. | Создать событие «ВНИМАНИЕ» с комментарием |
| 🚨 Тревога | Создать событие «ТРЕВОГА» с комментарием |
| Очистить | Закрыть ВСЕ события локации |
| 📜 История | История событий только этой локации |

## Вкладка «Оповещения»

Два режима запуска (переключатель сверху):

### 📋 По шаблону

1. Выберите сценарий (карточки подсвечиваются цветом серьёзности);
2. Отметьте локации — у каждой показано количество абонентов **с учётом выбранного шаблона**;
3. Нажмите «ЗАПУСТИТЬ ОПОВЕЩЕНИЕ (N локаций)» и подтвердите.

Запуск уходит массово: обзвон + Matrix-уведомление в комнату каждой локации.

### 🎙️ Своё сообщение (студия)

1. **Подготовьте сообщение** — три способа:
   - **🎙️ Записать** — запись с микрофона браузера (работает только по HTTPS — у пульта он есть); кнопка превращается в «⏹ Стоп», идёт счётчик секунд; после остановки доступно прослушивание;
   - **📤 Загрузить файл** — готовый WAV/MP3/OGG/WEBM с диска диспетчера;
   - **♻️ Ранее записанное** — выбор из списка уже сконвертированных файлов системы (тот же список, что во вкладке «Аудиофайлы»);
   - под плеером появляется предпрослушивание **«Так это услышит Астериск»** — WAV 8 kHz mono, именно этот файл уйдёт в обзвон и в Matrix.
2. **Текст в Matrix (необязательно)** — текстовая версия сообщения в комнаты локаций;
3. **🎧 Отправить звуковое сообщение** — тумблер: записанный WAV уйдёт в Matrix-комнаты голосовым сообщением (плеер в комнате);
4. **Локации** — отметьте получателей;
5. **«🚀 ЗАПУСТИТЬ ТЕСТОВОЕ ОПОВЕЩЕНИЕ»** — обзвон выбранных локаций этим файлом.

Кнопка **«❌ Отмена»** сбрасывает студию в начальное состояние (останавливает запись, чистит выбор и текст).

> Новая запись сбрасывает выбор «ранее записанного» файла — иначе непонятно, что именно отправлять.

## Вкладка «История»

Единая лента событий всех локаций: обзвоны, тревоги, внимания, закрытия, очистки. Колонка **Campaign ID** связывает событие с обзвоном; кнопка **«Детали»** открывает разбор кампании:

- **Итоги обзвона** — по каждому номеру финальный статус:

| Статус | Значение |
|---|---|
| ✅ Дослушано | абонент прослушал сообщение до конца |
| ⏹ Бросил трубку | ответил, но повесил трубку до конца |
| 📵 Не ответил | дозвон не был снят |
| 🔔 Занято | линия занята |
| ❌ Сброшен | звонок сброшен системой |
| ⚠️ Недоступен / Перегрузка | провайдер не принял вызов; система автоматически повторяет попытки (до 4 раз с ростом интервала), и только потом помечает номер недоступным |
| 🕐 В процессе | звонок ещё идёт или ждёт очереди |

- **Запуск** — результат постановки в очередь по каждому абоненту.

Если абонент «не получил» звонок — сначала смотрите «Детали»: там видно, была ли попытка, ретрай и с каким итогом завершился вызов.

## Вкладка «Аудиофайлы»

Библиотека звуковых файлов системы:

- **Загрузка** — кнопка «📤 Загрузить» + привязка к шаблону через селект (файл сразу станет звуком сценария);
- **Прослушивание** — кнопка «▶» (играет конвертированный WAV 8 kHz);
- **Удаление** — запрещено, если файл привязан к шаблону (кнопка серая): сначала отвязать/заменить звук шаблона.

Файлы, записанные в студии, также попадают в эту библиотеку и доступны для повторного использования через «♻️ Ранее записанное».

## Цеховые пульты (desk)

Упрощённый интерфейс для рабочих мест: `https://it-srv.vpk-oil.ru/incident-dashboard/desk/{код_локации}`

- только кнопки тревог своей локации, без истории и настроек;
- доступ ограничен белым списком IP локации (`allowed_ips`) — с чужого адреса пульт не откроется.

---

## Запуск через IVR (телефоном)

Сценарии с бейджем `IVR: код` запускаются звонком на внутренний номер запуска: после ответа наберите код сценария — система запустит обзвон по привязанным локациям и запишет инициатора в историю.

## Частые вопросы

**Микрофон не записывается.** Пульт должен быть открыт по HTTPS (это так) и браузер должен иметь разрешение на микрофон для сайта. Проверьте значок камеры/микрофона в адресной строке.

**Звонок «не пришёл» абоненту.** Откройте История → Детали кампании: статусы показывают реальную картину (бросил трубку / занят / недоступен после ретраев). «⚠️ Недоступен» после 4 попыток — честный диагноз, а не потеря: номер либо выключен, либо вне сети.

**Светофор красный: «транк НЕТ РЕГИСТРАЦИИ».** Внешние звонки не пройдут совсем. Внутренние работают. Сообщите администратору телефонии — проблема на стороне провайдера/регистрации SIP.

**Светофор красный: Matrix-бот.** Протух токен бота или недоступен homeserver — обзвон пройдёт, но текстовые и голосовые уведомления в комнаты не уйдут. Требуется перевыпуск токена.
