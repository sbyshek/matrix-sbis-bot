# Руководство пользователя

## Запуск оповещения

### Способ 1: Готовый сценарий

1. Откройте вкладку **📢 Оповещения**
2. Выберите сценарий (например, «Пожарная тревога»)
3. Отметьте локации для оповещения
4. Нажмите **🚀 ЗАПУСТИТЬ ОПОВЕЩЕНИЕ**

![Запуск по шаблону](assets/screenshot-dashboard.png)

### Способ 2: Своё сообщение

1. Переключитесь на **🎙️ Своё сообщение**
2. Нажмите **🎙️ Записать** и надиктуйте сообщение
3. (Опционально) Добавьте текст для Matrix
4. Выберите локации
5. Нажмите **🚀 ЗАПУСТИТЬ ТЕСТОВОЕ ОПОВЕЩЕНИЕ**

![Студия записи](assets/screenshot-studio.png)

## Системный светофор

Светофор в левом верхнем углу показывает состояние системы:

| Цвет | Значение |
|------|----------|
| 🟢 Зелёный | Все системы работают |
| 🟡 Жёлтый | Предупреждения (транки забиты) |
| 🔴 Красный | Критические проблемы |

Нажмите на светофор для детальной информации.

## История событий

Вкладка **📜 История** показывает все события:

- 📞 Обзвоны (с деталями по каждому номеру)
- 🚨 Тревоги и ⚠️ Внимания
- ✅ Закрытые события
- 🧹 Очистки

## Управление аудиофайлами

Вкладка **🎧 Аудиофайлы**:

- Загрузка новых файлов (WAV, MP3, OGG)
- Привязка к шаблонам
- Прослушивание и удаление

## Цеховые пульты

Для рабочих мест используйте упрощённый интерфейс: 

```url
https://it-srv.vpk-oil.ru/incident-dashboard/desk/{location_id}
```
