# 📡 Руководство по интеграции с Alert Bus API

## 🔑 Базовые параметры
| Параметр | Значение |
|----------|----------|
| **Endpoint** | `POST http://<IP_СЕРВЕРА>:8765/api/v1/ingest` |
| **Content-Type** | `application/json` |
| **Authorization** | `Bearer <ваш_токен>` (выдаётся администратором) |
| **Поле `source`** | ❌ **Не передавать!** Определяется автоматически по токену |

---

## 📦 Структура JSON-запроса
```json
{
  "location": "Цех Розлива, Линия 3",
  "parameter": "Давление в магистрали",
  "value": 5.8,
  "unit": "МПа",
  "min_val": 2.0,
  "max_val": 5.0,
  "description": "Превышение верхнего порога! Требуется сброс давления",
  "severity": "warning",
  "context": {
    "Смена": "2",
    "Оператор": "Иванов А.П."
  },
  "meta": {
    "Температура верха K-001": 96.1,
    "Расход сырья": 120.5
  }
}
```

### 📝 Описание полей
| Поле | Тип | Обязательно | Описание |
|------|-----|-------------|----------|
| `location` | `string` | ❌ | Место/установка |
| `parameter` | `string` |  | Наименование параметра |
| `value` | `float` |  | Текущее значение (используй `.` как разделитель) |
| `min_val` / `max_val` | `float` | ❌ | Границы нормы |
| `description` | `string` | ❌ | Комментарий / действия |
| `severity` | `string` | ✅ | `info` / `warning` / `critical` (по умолчанию `info`) |
| `context` | `object` | ❌ | Контекст события (время, смена, оператор) |
| `meta` | `object` |  | Дополнительные параметры процесса (ключ-значение) |

## 🧪 Примеры запросов

### 🐍 Python
```python
import requests

url = "http://192.168.1.100:8765/api/v1/ingest"
headers = {
    "Authorization": "Bearer sk_your_token_here",
    "Content-Type": "application/json"
}
payload = {
    "location": "Серверная 1",
    "description": "Блокировка доступа",
    "severity": "warning",
    "context": {"Смена": "3"}
}

resp = requests.post(url, json=payload, headers=headers)
print(resp.status_code, resp.json())  # Ожидаемо: 201 {"status": "ok", "source": "..."}
```

### 🌐 cURL
```bash
curl -X POST http://192.168.1.100:8765/api/v1/ingest \
  -H "Authorization: Bearer sk_your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "location": "Склад ГСМ",
    "parameter": "Уровень топлива",
    "value": 12.5,
    "severity": "info"
  }'
```

##  1С:Предприятие 8.3
Полностью рабочий пример процедуры для отправки алерта.

```bsl
// Функция отправки алерта в Matrix Alert Bus
// Токен выдается администратором системы оповещений
Процедура ОтправитьАлертВMatrix(Токен, АдресСервера = "192.168.1.100", Порт = 8765)
    
    Попытка
        HTTP = Новый HTTPСоединение(АдресСервера, Порт);
    Исключение
        Предупреждение("Ошибка создания HTTP-соединения: " + ОписаниеОшибки());
        Возврат;
    КонецПопытки;

    // 1. Формируем заголовки
    Заголовки = Новый HTTPЗаголовок;
    Заголовки.Вставить("Content-Type", "application/json");
    Заголовки.Вставить("Authorization", "Bearer " + Токен);

    // 2. Формируем данные (Структура автоматически конвертируется в JSON)
    Данные = Новый Структура;
    Данные.Вставить("location",     "Цех АВТ-800");
    Данные.Вставить("parameter",    "Температура реактора");
    Данные.Вставить("value",        145.5);          // Числа с плавающей точкой
    Данные.Вставить("unit",         "°C");
    Данные.Вставить("min_val",      120.0);
    Данные.Вставить("max_val",      140.0);
    Данные.Вставить("description",  "Превышение нормы! Снизить подачу пара.");
    Данные.Вставить("severity",     "warning");      // info | warning | critical
    
    // Контекст и Метаданные (вложенные объекты)
    Данные.Вставить("context", Новый Структура("Смена, ВремяПоЖурналу", 2, "06.05.2026/16:00"));
    Данные.Вставить("meta",    Новый Структура("Давление, Расход", 0.8, 120.5));

    // 3. Сериализация в JSON
    ЗаписьJSON = Новый ЗаписьJSON;
    ЗаписьJSON.УстановитьСтроку();
    ЗаписатьJSON(ЗаписьJSON, Данные);
    ТелоЗапроса = ЗаписьJSON.Закрыть();

    // 4. Отправка POST-запроса
    Попытка
        Ответ = HTTP.ОтправитьДляОбработки("POST", "/api/v1/ingest", ТелоЗапроса, Заголовки);
        
        Если Ответ.КодСостояния = 201 Тогда
            // Успешно
            ЧтениеJSON = Новый ЧтениеJSON;
            ЧтениеJSON.УстановитьСтроку(Ответ.ПолучитьТелоКакСтроку());
            Результат = ПрочитатьJSON(ЧтениеJSON);
            Сообщить("✅ Алерт отправлен. Источник: " + Результат.source);
        Иначе
            Сообщить(" Ошибка API: Код " + Ответ.КодСостояния + " | " + Ответ.ПолучитьТелоКакСтроку());
        КонецЕсли;
        
    Исключение
        Сообщить("❌ Ошибка отправки: " + ОписаниеОшибки());
    КонецПопытки;

КонецПроцедуры
```

### ⚠️ Важные нюансы для 1С
1. **Разделитель дробных чисел:** 1С использует запятую в коде, но `ЗаписатьJSON` корректно экранирует числа в JSON-формат (с точкой). Не преобразовывай числа в строки вручную.
2. **Поле `source`:** Не добавляй его в `Структуру`. Сервер подставит его сам на основе токена.
3. **Объекты:** `context` и `meta` передавай как вложенные `Структура` или `Соответствие`. Они автоматически станут JSON-объектами `{...}`.
4. **Лимиты:** Максимальный размер тела запроса ограничен стандартными настройками FastAPI (~1MB). Для текстовых алертов этого более чем достаточно.

##  Ответы API
| Код | Описание |
|-----|----------|
| `201 Created` | ✅ Алерт принят и передан в шину |
| `400 Bad Request` | ❌ Ошибка валидации JSON (проверь типы полей) |
| `401 Unauthorized` | ❌ Отсутствует или неверный заголовок `Authorization` |
| `403 Forbidden` | ❌ Токен отозван или не активен |
