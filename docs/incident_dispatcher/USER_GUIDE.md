# 📡 Диспетчерский пульт — инструкция пользователя

Пульт — единое окно оператора: контроль локаций, события «Внимание»/«Тревога» и голосовые оповещения (обзвон абонентов + сообщение в Matrix). Всё, что вы делаете на пульте, сразу видно на цеховых пультах и в Matrix-комнатах локаций.

---

## 1. Вход и устройство пульта

1. Откройте ссылку, выданную администратором.
2. Доступ разрешён с рабочих мест диспетчеров (по IP). Если видите «Доступ запрещён» — обратитесь к администратору.
3. Три вкладки:
   - **📍 Локации** — контроль и управление по каждой локации (обновляется автоматически каждые ~5 секунд);
   - **📢 Оповещения** — массовый запуск по шаблону и студия записи своего сообщения;
   - **📜 История** — единый журнал событий и обзвонов по всем локациям.

---

## 2. Вкладка «📍 Локации»

Каждая локация — карточка с цветной рамкой: 🟢 зелёная — НОРМА, 🟠 оранжевая — ВНИМАНИЕ, 🔴 красная — ТРЕВОГА.

### 2.1. Сценарии оповещения
- У каждого сценария: название, текст сообщения, код **IVR** (по нему сценарий запускается с телефона) и кнопка **«▶ Запустить обзвон»**.
- Если сценариев много, виден первый, остальные — по кнопке **«⋯ Все сценарии (N)»**.

**Запуск обзвона по локации:**
1. Нажмите **«▶ Запустить обзвон»** на нужном сценарии.
2. Подтвердите действие.
3. Откроется окно результата: «📊 Кампания: N успех, M ошибок» и список абонентов (✅ в очереди / ❌ ошибка с причиной).

### 2.2. Список оповещения
Кнопка **«👥 Список оповещения (N)»** открывает окно со всеми, кого оповещает локация. Работает поиск по номеру, коду и описанию.

### 2.3. События «Внимание» / «Тревога»
- **Создать:** кнопка **«⚠️ Вним.»** или **«🚨 Тревога»** → введите комментарий → событие появится на карточке, рамка сменит цвет, в Matrix-комнату локации уйдёт сообщение.
- **Закрыть одно:** ✕ на событии.
- **Закрыть все:** кнопка **«Очистить»**.

### 2.4. История локации
Кнопка **«📜 История»** — окно с журналом событий и обзвонов именно этой локации.

---

## 3. Вкладка «📢 Оповещения»

Сверху — переключатель режима: **«📋 По шаблону»** или **«🎙️ Своё сообщение»**.

### 3.1. По шаблону (массовое, на несколько локаций)
1. Выберите сценарий (карточка подсветится).
2. Отметьте локации; рядом с каждой видно, **сколько абонентов** будет обзвонено; можно «Выбрать все».
3. Нажмите **«🚀 ЗАПУСТИТЬ ОПОВЕЩЕНИЕ (N локаций)»** и подтвердите.
4. Проверьте окно результата: успешно/не удалось по каждой локации.

### 3.2. Своё сообщение (студия записи)
1. Переключитесь в режим **«🎙️ Своё сообщение»**.
2. Нажмите **«🎙️ Записать»** и разрешите доступ к микрофону. Говорите четко, после — **«⏹ Стоп»**.
3. Прослушайте запись в плеере. Не понравилось — **«🎙️ Перезаписать»**.
4. При желании впишите текст для Matrix (необязательно).
5. Отметьте локации и нажмите **«🚀 ЗАПУСТИТЬ ТЕСТОВОЕ ОПОВЕЩЕНИЕ»**.
6. Запись загрузится и сконвертируется в телефонный формат — появится плеер **«🔊 Так это услышит Астериск»**, и начнётся обзвон.

> ⚠️ Запись с микрофона работает по HTTPS либо при специальной настройке браузера. Если микрофон недоступен — обратитесь к администратору.

---

## 4. Вкладка «📜 История»

Единый журнал по всем локациям: тревоги/внимания, закрытия, очистки, обзвоны (включая тестовые и IVR-запуски).

Кнопка **«Детали»** у обзвона открывает карточку кампании:
- **📊 Итоги обзвона** — по каждому номеру фактический результат;
- **🚀 Запуск** — кто был поставлен в очередь при запуске и без ошибок ли.

### Статусы звонков
| Статус | Значение |
|---|---|
| ✅ Дослушано | абонент дослушал сообщение до конца |
| ⏹ Бросил трубку | абонент ответил, но прервал прослушивание |
| 📵 Не ответил | дозвон не состоялся, абонент не взял трубку |
| 🔔 Занято | номер занят |
| ❌ Сброшен | вызов сброшен |
| ⚠️ Недоступен / Перегрузка | номер недоступен или сеть перегружена |
| 🕐 В процессе | звонок ещё идёт |

---

## 5. Правила безопасности

1. **Запуск оповещения — это реальные звонки реальным людям** и сообщения в Matrix. Нажимайте запуск только убедившись, что выбраны верный сценарий и верные локации.
2. Для тренировок и проверок связи используйте **учебные сценарии** или студию записи с тестовой фразой («Раз-два-три, проверка связи»).
3. Коды IVR на карточках (например, `IVR: 1001`) — для запуска сценария с телефона: звонок на **8000** → ввод кода. Учитывайте это при проверках.
4. Цеховые пульты работают автономно: события и обзвоны, созданные с них, видны на вашем пульте и в истории.

---

## 6. Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| «Доступ запрещён» | Ваш IP не в списке — к администратору |
| «❌ Микрофон недоступен» | См. примечание в п. 3.2 — к администратору |
| В результате «0 успешно / N ошибок» | Откройте список: у абонентов «занято»/«недоступен» — повторите запуск позже |
| Пульт «завис» или данные старые | Обновите страницу: **Ctrl + F5** |
| Обзвон не идёт ни по одной локации | Возможно, нет связи с телефонией — срочно сообщите администратору |
